## Java advance course:

This repository contains practical code and exercises from my Advanced Java course. It showcases my course projects each of which received a perfect score (100). 
The projects demonstrate both core and modern Java features through real-world patterns, libraries, and structured project design.


## Key Skills Developed:

Deep understanding of object-oriented programming concepts: inheritance, polymorphism, encapsulation, abstraction.

Advanced use of Java Collections Framework (Lists, Sets, Maps, Queues, and their implementations).

Exception handling and creating custom exceptions.

Working with Java I/O streams and file handling.

Mastery of Java Generics for type-safe code.

Understanding of Java memory management, garbage collection, and performance optimization.

## Concurrency & Multithreading

Writing multithreaded programs using Thread and Runnable.

Synchronization, locks, and thread-safe programming.

Using concurrent utilities like ExecutorService, CountDownLatch, and ConcurrentHashMap.

Understanding deadlocks, race conditions, and thread lifecycle.

## GUI & Event-Driven Programming

Building desktop applications using Swing and JavaFX.

Handling events, listeners, and user interactions.

Layout management and UI design principles.

## Networking & APIs

Creating networked applications using sockets (TCP/UDP).
